# 📖 Основные понятия Flexbox

## Flex-контейнер и flex-элементы

* **Flex-контейнер** — элемент с ```display: flex```
* **Flex-элементы** — дочерние элементы внутри контейнера

## Основные свойства Flexbox:
**1.** ```flex-direction``` — определяет направление элементов (```row, column, row-reverse, column-reverse```)

**2.** ```justify-content``` — выравнивание по главной оси (```flex-start, flex-end, center, space-between, space-around, space-evenly```)

**3.** ```align-items``` — выравнивание по поперечной оси (```stretch, flex-start, flex-end, center, baseline```)

**4.** ```flex-wrap``` — управление переносом элементов (```nowrap, wrap, wrap-reverse```)

**5.** ```gap``` — отступы между элементами

**6.** ```flex-grow, flex-shrink, flex-basis``` — управление размерами элементов

**7.** ```align-self``` — индивидуальное выравнивание элемента

# 🧪 Практические примеры
1. Горизонтальное навигационное меню
    * Использование ```justify-content: space-around```
    * Стилизация ссылок и эффект наведения

2. Карточки товаров
    * Адаптивное расположение с ```flex-wrap: wrap```
    * Использование ```flex: 1 1 250px``` для гибкости
    * Выравнивание кнопки внизу карточки

3. Центрирование элемента
    * Простое центрирование с помощью ```justify-content: center и align-items: center```
